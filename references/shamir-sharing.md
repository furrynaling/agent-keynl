# Shamir 门限分片

## 为什么需要分片

单主密码的风险：

```
主密码 "my_master_password"
  ├── 忘了 → 密钥库永远打不开 ❌
  ├── 泄露 → 所有密钥全暴露 ❌
  └── 只存一处 → 单点故障 ❌
```

Shamir 门限分片把主密码拆成 N 份，任意 K 份可恢复：

```
N=5, K=3  →  5 个分片，任意 3 个可恢复
```

## 原理

Shamir Secret Sharing（沙米尔秘密共享）基于多项式插值：

```
秘密 = 多项式在 x=0 处的值
分片 = 多项式在 x=1,2,3,4,5 处的值

恢复：任意 3 个点 → 唯一确定 2 次多项式 → 求 x=0 的值
```

**数学保证**：
- 少于 K 份分片 → 信息论上无法恢复（不是"很难"，是"不可能"）
- 恰好 K 份 → 唯一恢复
- 多余 K 份 → 冗余校验

## 分片策略（3-of-5）

```
分片1 → 云端备份（如 GitHub 私密库）
分片2 → 另一云端（如腾讯云）
分片3 → 随身 U 盘
分片4 → 家里保险箱
分片5 → 信任的朋友

丢失 1-2 份 → 仍可恢复（还有 3 份）
泄露单份   → 无法恢复（需要 3 份）
```

## 使用

```bash
# 生成分片
echo "主密码" | keynl shards

# 输出 5 个文件
/root/mytp/.keys/shards/
  ├── shard_1.key
  ├── shard_2.key
  ├── shard_3.key
  ├── shard_4.key
  ├── shard_5.key
  └── info.txt   ← 说明哪些分片放哪
```

## 恢复

任意 3 个分片 → shamir_recover() → 主密码

```python
from keynl import shamir_recover
shares = {1: ..., 3: ..., 5: ...}  # 任意3个
password = shamir_recover(shares).decode()
```

## 安全边界

| 情况 | 结果 |
|:---|:---|
| 拿到 1-2 份分片 | ❌ 信息论上无法恢复 |
| 拿到 3 份分片 | ✅ 恢复主密码 |
| 丢失 1-2 份 | ✅ 仍可恢复 |
| 丢失 3 份以上 | ❌ 永久丢失 |

**注意**：分片本身也要妥善保存——分片泄露到别人手里，凑齐 3 份就能恢复。
