# 硬件指纹绑定

## 核心思想

> 密文离开原服务器 = 一块废铁。

加密时把服务器的硬件指纹混入密钥派生，解密时重新采集比对。密文复制到任何其他机器都无法解密。

## 采集的四个值

```python
def get_hw_fingerprint():
    parts = [
        # 1. 机器 ID（systemd 生成，重装系统才变）
        SHA256(open('/etc/machine-id').read())[:16],
        
        # 2. 主机名
        SHA256(hostname)[:16],
        
        # 3. 内核版本
        SHA256(uname -r)[:16],
        
        # 4. MAC 地址（网卡物理地址）
        SHA256(ip link show eth0 | grep ether)[:16],
    ]
    return ''.join(parts)
```

## 混合逻辑

```
加密: 密钥 = Argon2id(密码, 硬件指纹)
解密: 密钥 = Argon2id(密码, 重新采集的指纹)
      ↑ 指纹不同 → 密钥不同 → 解密失败
```

## 攻击场景

| 场景 | 结果 |
|:---|:---|
| 复制 vault.enc 到另一台服务器 | ❌ 指纹不匹配 |
| 克隆整个磁盘到不同硬件 | ❌ MAC/机器ID 变化 |
| 换网卡 | ⚠️ MAC 变化 → 需重建 |
| 重装系统 | ⚠️ 机器ID 变化 → 需重建 |
| 升级内核 | ⚠️ 内核版本变化 → 需重建 |

## 迁移 / 恢复

需要迁移密钥库到新服务器时：

1. 先在新服务器上 `keymgr`（无参数）生成新指纹
2. 记录新指纹
3. 用 Shamir 分片恢复主密码
4. 在新服务器用主密码重建 vault

## 局限与应对

**硬件指纹不是万能的**：

- **内核升级**会变 → 系统自动更新前需备份
- **网卡更换**会变 → 换网卡前需迁移
- **容器迁移**会变 → 容器环境指纹不稳定

**应对**：指纹变化后，用 Shamir 分片恢复主密码，重建指纹绑定。

## 进阶：TPM 2.0

条件允许时，用真实 TPM 芯片指纹替代软件采集：

```
TPM 2.0 提供硬件级指纹（PCR 寄存器值）
  → 无法被软件伪造
  → 比 MAC/机器ID 更可靠
```

但 TPM 需要物理硬件支持，云服务器通常不提供。
